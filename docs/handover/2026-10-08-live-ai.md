## Setup on another machine

Update from this GitHub branch using the shared workflow. No dependency or database migration is required. Each machine needs its own ignored `ELEVENLABS_API_KEY` and `ELEVENLABS_AGENT_ID`, then a preview restart. Never commit `.dev.vars` or the private agent snapshot. A source-code pull alone cannot transfer those settings.
