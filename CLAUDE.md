# Daywell: shared project instructions

Read and follow [AGENTS.md](AGENTS.md) and [the GitHub session workflow](docs/github-workflow.md) at the start of every session.

These are shared rules for both machines and all coding assistants. GitHub is the source of truth. Fetch before working; at the end of the session, commit and push the work, leave a GitHub handover, and verify the remote commit. A local preview alone is not a completed handover.
